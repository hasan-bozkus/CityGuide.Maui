## Projenin Temel Maksadı
Milano Şehir Rehberi, Türk kullancılarının Milano şehri hakkında bilgi sahibi olabileceği, gidilip görülmesi lazım gelen mekanlar hakkında bilgi sahibi olabilecekleri, gerekirse nasıl ve ne şekilde gidebileceklerini kolaylaştıran bir mobil uygulamasıdır.

.Net Maui -.Net Android 10.0 temelli, SqLite, rapid api ve xaml teknolojileri geliştirme esnasında kullanıldı.

"Proje işinize yaradıysa veya referans almak isterseniz GitHub üzerinden bir ⭐ bırakarak destek olabilirsiniz, şimdiden teşekkürler!"

## Kullanılan Teknolojiler
### Backend
💎 .Net Maui - Android 10.0 <br />
💎 SqlLite <br />
💎 Rapid Api <br />
💎 Google Gemini: Veri Hazırlama <br />


### Frontend
💎 Xaml <br />
💎 Stitch AI: Kullanılan Temanın Html Formatta Hazırlanması <br />
